# Mercor alignment notes

This portfolio was aligned using Mercor’s public opportunity pages because the applications area requires sign-in. The portfolio does not claim senior or professional production experience that is not present in Yarram’s resume.

Mercor’s public Software Engineering Expert listing describes project-based, remote AI training and evaluation work. It emphasizes shipped software, clear written communication, and comfort with ambiguous tasks. It also describes work such as writing engineering problems from systems someone has built and reviewing model-written code for edge cases, complexity, tests, and production failure modes. [1]

The public Engineering Expert listing similarly emphasizes project-based work, clear reasoning, and flagging unclear instructions, but its degree and professional design/analysis requirements do not match Yarram’s current profile. The portfolio therefore positions him as an early-career web developer and AI/ML student open to focused project-based work, rather than as an engineering expert. [2]

The public Explore page describes Mercor as a project-matching marketplace with remote opportunities across different domains. [3]

Implemented alignment choices:

- Hero availability now says “Open to project-based web work”.
- Hero copy now foregrounds clear communication, practical shipping, interface care, and willingness to learn.
- A “Where I can contribute” strip names web development, HTML/CSS/JavaScript, UI implementation, AI/ML learning, clear written reasoning, and remote-friendly work.
- About copy now emphasizes practical, project-based opportunities and explaining thinking clearly.
- Existing SmartFarm evidence remains the main proof of work; no invented production experience, LinkedIn URL, or Mercor-specific title was added.
